# Output

**Development workflow only** — `npm run build` writes here when stock is in `in/`.

With an explicit stock path (zero-install), output is written **beside the input file** instead. See [Quick start](../README.md#quick-start).

`npm run build` writes **`Z10PEWS.CAP`** here for USB BIOS FlashBack.

Generated images are gitignored — only this README is tracked.
